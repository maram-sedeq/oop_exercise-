# Dart OOP Concepts

This repository contains practical examples of the main Object-Oriented Programming (OOP) concepts in Dart.

## Concepts Covered

1. **Encapsulation** – Protecting data using private properties and getters/setters.
2. **Inheritance** – Reusing properties and methods from parent classes.
3. **Polymorphism** – Using a common interface with different implementations.
4. **Abstraction** – Hiding implementation details using abstract classes.
5. **Composition** – Building classes by combining objects.

## Files

- `encapsulation.dart`
- `inheritance.dart`
- `polymorphism.dart`
- `abstraction.dart`
- `composition.dart`
